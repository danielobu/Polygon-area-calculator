# Polygon Area Calculator

A Python Object-Oriented Programming (OOP) project built as part of the freeCodeCamp Scientific Computing with Python certification.

## Features
- **Rectangle Class**: Computes area, perimeter, diagonal, and visual representations using string multiplication.
- **Square Class**: Subclass of `Rectangle` with synchronized dimensions to guarantee side equality.
- **Shape Fitting**: Calculates how many times a given shape fits inside another shape without rotation.

## Technologies Used
- Python 3
- Object-Oriented Programming (Inheritance, Method Overriding, Polymorphism)
